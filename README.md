# XGBoost Churn Prediction Model

An **XGBoost-based Churn Prediction Model** designed for an **E‑commerce platform**, developed as a sub‑repository of the **Smart Retention Project**.  
This project integrates a **full‑stack Django e‑commerce system**, a **hybrid recommendation engine**, and a **churn prediction pipeline** to identify and retain at‑risk customers.
